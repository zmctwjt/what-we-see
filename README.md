## 作品命题

**我们看到的宇宙，不是宇宙的样子，是我们的仪器能看见的样子。**

1992 年至今，人类确认了 6,451 颗围绕其他恒星运行的行星。
但这份目录不是宇宙的清单——它是四类探测方法各自的「观测窗口」叠加后的结果。

凌星法要求行星轨道近似正对地球（概率仅约 0.5%），视向速度法对质量敏感，
微引力透镜能看见极远系统却无法复观，直接成像必须遮挡恒星强光。

本作品把「观测偏差」本身作为可视化对象，而不是试图校正它。

## 关键证据

同一指标，不同方法之间相差数千倍：

| 指标 | 凌星法中位 | 对照方法中位 | 倍数 |
|---|---|---|---|
| 轨道周期 | 7.97 天 | 33,200 天（直接成像） | **4,165 倍** |
| 行星半径 | 2.46 R⊕ | 12.60 R⊕（视向速度） | **5.1 倍** |
| 距地距离 | 459 pc | 6,280 pc（微引力透镜） | **13.7 倍** |

方法构成：凌星法 74.2%、视向速度法 18.7%，两者合计 **92.8%**。

半径谷（不预设区间，由数据检测）：谷底 **1.875 R⊕**，比两侧峰低 **29.7%**，
在 4 个子样本中复现。

## 交互

- **拖拽框选** 周期 × 半径，实时显示区间与方法构成
- **拖拽刷选** 年份区间，全站按年收窄
- **点击播放** 年份 1992→2026 推进，面积图逐帧生长
- **数量 / 占比** 切换，看规模或结构
- **方法多选**，其他视图同步高亮
- **悬停 / 点击** 单颗行星，固定并查看完整参数

六个视图共享同一筛选状态，顶部状态栏实时显示「6,451 颗中的多少颗」。

## 数据来源

| 项 | 内容 |
|---|---|
| 来源 | NASA Exoplanet Archive（TAP 服务） |
| 表 | `pscomppars`（官方复合参数表，一行一颗行星） |
| 规模 | 6,451 颗唯一行星，4,847 个宿主恒星，1992–2026 |
| 授权 | NASA 公开数据，无需账号或密钥 |

> **为什么不用 `ps` 表**：`ps` 共 40,350 行，其中 5,514 颗行星出现多次
> （TrES-2 b 出现 34 次）。直接统计会虚增 6 倍以上。
> `pscomppars` 行数 6,451 = 唯一行星名数 6,451，证明无重复。

## 技术

Vite 5 + 原生 SVG + 原生 DOM，无前端框架、无图表库。
数据与代码分离，纯静态站点，可部署于任意静态服务器。

**本地运行**：解压后 `npm install && npm run build`，或直接起静态服务器打开 `dist/`。

> ⚠️ 不要直接双击 `index.html`：`file://` 协议下浏览器会拦截 ES 模块，页面空白。
